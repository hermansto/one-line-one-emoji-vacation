One emoji for my dream vacation: 🏝️

No plane, no suitcase, no itinerary — just a desert island. Palm, sand, and nowhere to be. That is the whole trip.

`main.ts` writes that single emoji to `entry.txt` in the output directory, exactly, with no trailing newline, and verifies it byte-for-byte.

Run it locally:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/one-emoji-vacation-out node main.ts
```
